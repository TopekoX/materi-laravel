# Peta Belajar: Deployment dan DevOps

Bab utama ini membawa aplikasi dari laptop ke produksi: server Linux/VPS, Nginx, PHP-FPM, MySQL, deploy, Supervisor, HTTPS, Docker, CI/CD, backup, dan monitoring.

!!! danger "Belum teruji penulis"
    Penulis tidak menjalankan materi ini pada VPS atau Docker sungguhan. Hanya sintaks `compose.yaml` dan workflow GitHub Actions yang diperiksa lokal. Kerjakan di server uji dan verifikasi sendiri.
