# Belajar Laravel

Materi belajar **Laravel 13.x** dalam bahasa Indonesia, dari dasar web dan PHP sampai arsitektur
profesional, disusun dalam 12 bab utama sesuai kurikulum.

<div class="grid cards" markdown>

- :material-school: **[Kurikulum](curriculum/index.md)**

    12 bab utama, 235 sub bab, dan status penulisannya.

</div>

## Cara belajar

1. Siapkan PHP 8.3+ dan Composer.
2. Ikuti bab sesuai urutan di kurikulum.
3. Ketik sendiri kodenya, jalankan, lalu cocokkan dengan hasil yang diharapkan.
4. Kerjakan latihan di akhir setiap bab.

!!! tip "Fitur situs"
    Gunakan tombol tema di header (sistem, terang, gelap), kolom pencarian, dan
    tombol salin pada setiap blok kode.
